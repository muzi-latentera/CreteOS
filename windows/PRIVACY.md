# CreteOS Windows data and services

This Windows fork inherits LiftOff's integrations. Account connections are optional. Local settings, discovered libraries, collections and cached art/media are stored under `%LOCALAPPDATA%\CreteOS`. WebView data uses the `io.latent.creteos.windows` application identity. Supported account tokens use the Windows credential store through the inherited keyring integration, with separate CreteOS namespaces.

Depending on enabled features, the launcher contacts Steam, Microsoft/Xbox, Spotify, SteamGridDB, cloud gaming/catalog services and media sources. Those services receive the requests needed for their features and have their own privacy policies. Microsoft/Steam sign-in, Spotify playback and artwork/download functions retain upstream behavior; this fork has not independently audited every integration.

Home’s optional-content ‘What’s new’ rail requests the public Reddit r/Games + r/pcgaming RSS feed, without account authentication. Thumbnails use Reddit image hosts, embedded YouTube previews and article Open Graph images from a fixed gaming-publication allowlist. Article preview requests have bounded sizes/timeouts and do not follow redirects. Articles open in your default browser. Feed results, including failures, are cached in memory for 30 minutes; the rail is hidden when no entries are available.

Crete game details search public YouTube pages for the game title and preferred reviewers, without account authentication. These searches send the game title to YouTube. Preferred channels are Whitelight, Skill Up, Joseph Anderson, Noah Caldwell-Gervais, gameranx and Jake Baldino. Matching results are cached locally for seven days; empty results for one hour. Selecting a review opens YouTube in the default browser. Microsoft-account title details, achievement summaries and available MinutesPlayed statistics use the existing credential-store sign-in and account-scoped local caches. An exact Steam-title match can supply missing informational media for an Xbox title; it does not alter its ownership or launch identity.

GeForce NOW launches use the detected NVIDIA client. CreteOS reads NVIDIA-created desktop shortcut targets/arguments and prefers a matching game and store variant; it never executes arbitrary shortcut targets. The quality dialog saves per-display preferences in CreteOS. Applying them requires NVIDIA’s client/streamer to be closed, validates the detected settings schema, preserves unrelated fields and saves a backup under `%LOCALAPPDATA%\CreteOS-Bootstrap\gfn-settings` before changing custom resolution, frame rate and bitrate. Those backups can contain NVIDIA account/session data and should remain private. Codec, membership limits and unsupported settings stay managed by NVIDIA. “Open game with current settings” leaves NVIDIA’s saved quality unchanged.

Moonlight host availability is cached per hostname in WebView local storage: advertised app names, installed Steam IDs/titles, Buddy pairing status/API version and refresh timestamps. No SSH keys or pairing credentials are stored in this snapshot. Configured hosts are queried in the background at most once per 24 hours; manual refresh and starting a stream can contact them immediately. Failed refreshes retain the saved data and record the attempt to avoid repeated automatic requests. Moonlight uses a detected local client, read-only SSH inventory and the pinned MoonDeck Buddy API. The normal factory reset also clears WebView storage.

Manual update checks contact GitHub for the CreteOS repository's releases and only select tags prefixed `windows-v`. Automatic update checks default to off. The Xbox cloud catalog refresh currently reads LiftOff's upstream GitHub data file. No CreteOS analytics service was added.

Disconnect accounts through Settings before removing local data. Factory reset removes launcher data, so export/back up configuration if needed. GPD tools and AnyFSE run as separate applications and retain their own settings and data handling. The profile generator writes the local executable paths you supply into its output; review that file before sharing it.

The bundled NVIDIA GB public catalogue contains game identities and store variants, without account credentials or ownership. A daily background refresh uses NVIDIA's public catalogue API; offline or failed refreshes retain saved data. Native direct launches select the matching store CMS ID, validated against this catalogue. Cloud installation and NVIDIA membership requirements still apply. The startup artwork temporarily keeps the CreteOS window on top while a matching game/stream window settles, with a two-minute fail-open watchdog; it does not inspect game pixels or infer when an in-game scene is playable.

Amazon Luna cloud URLs prefer the installed Luna Chrome app described by its desktop shortcut, using the existing Chrome profile and Chromium's documented app launch-URL override. CreteOS reads shortcut metadata, validates the fixed Chrome executable/app ID/profile flags and reconstructs the launch command; it does not copy browser credentials. Unsupported or missing installed Luna app information produces an error rather than silently choosing the default browser. NVIDIA native launch flags retain the exact raw quoting and working directory used by NVIDIA-created shortcuts. The artwork-only spinner hands off to NVIDIA's client or streamer window so login/queue/action prompts remain available; B/Escape can still dismiss the cover.
